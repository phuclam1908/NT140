## 2. Observation / Interpretation / giới hạn

**Observed:** Máy nhiễm Neris gửi nhiều HTTP POST tới cùng một HTTP Host và URI; các TCP sessions có hai chiều và đóng bình thường theo phân loại Zeek; máy chủ trả về HTTP status 200; thời gian giữa nhiều POST tập trung quanh 2 phút.

**Inferred:** Đây là **ứng viên HTTP C2/beaconing** có cơ sở để điều tra. README của dataset nói Neris có sử dụng HTTP C&C, nhưng chỉ các trường HTTP/connection **chưa tự chứng minh** payload cụ thể là lệnh C2. `200 OK` không đồng nghĩa lệnh được thực thi. Tên `/snapbn/ip.php` không đủ để xác nhận chức năng của URL.

**Chưa xác minh:** payload POST/response; nguồn frame/stream cụ thể; lý do các khoảng cách dài; xác nhận liên kết với nhãn ground truth ở mức thích hợp.

## 3. Tệp có sẵn và cách tái lập

- `reports/week1/generated/beaconing_results.csv` (nhóm `31.192.109.167:80`, 54 connections, mean interval ~144.04 s và CV ~0.563 tính trên **toàn bộ 54 connections**, khác với chỉ 53 POST).
- `reports/week1/generated/http_candidate_evidence.csv` (54 HTTP records được match theo UID).
- `reports/week1/generated/http_post_timeline.csv` (53 POST và `interval_s`).
- `reports/week1/generated/http_post_intervals.png` nếu đã tạo bằng script vẽ.

Cách kiểm tra nhanh trong môi trường Ubuntu (tại thư mục gốc repo, `.venv` đang kích hoạt):

```bash
python - <<'PY'
import pandas as pd
from pathlib import Path
p = Path('data/processed/scenario-01-neris/zeek')
c = pd.read_json(p/'conn.log', lines=True)
h = pd.read_json(p/'http.log', lines=True)
c = c[(c['id.orig_h']=='147.32.84.165')&(c['id.resp_h']=='31.192.109.167')&(c['id.resp_p']==80)]
h = h[h['uid'].isin(c['uid'])]
post = h[(h['method']=='POST')&(h['uri']=='/snapbn/gate.php')].sort_values('ts')
d = post['ts'].diff().dropna(); d = d[d>0]
print('connections=',len(c),'http=',len(h),'POST=',len(post))
print('median_s=',d.median(),'mean_s=',d.mean(),'CV_pop=',d.std(ddof=0)/d.mean())
PY
```
